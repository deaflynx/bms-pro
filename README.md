# bms-pro.com.ua — новий сайт

Чернетка нового сайту BMS Pro (прилади біомеханічної стимуляції мʼязів, ТОВ «УКРСИСТЕМС»).
Замінить наявний сайт на WordPress після узгодження.

**Макети:** https://deaflynx.github.io/bms-pro/

## Чому переробляємо

Наявний сайт на WordPress (Astra + Spectra + WooCommerce):

| | Зараз | Ціль |
|---|---|---|
| HTML головної | 686 КБ (з них ~601 КБ вбудованого CSS у 23 блоках) | < 60 КБ |
| HTML `/services/` | 1,0 МБ | < 60 КБ |
| Зовнішніх CSS / JS | 18 / 22 | 1 / 1 |
| Структуровані дані (JSON-LD) | немає | Organization, Product ×4, FAQPage, BreadcrumbList |
| Сторінок з контентом | 3 | 15 |
| Сторінка на прилад | немає (усі 4 на одній) | окрема на кожен |

`robots.txt` наявного сайту вже має коректний allowlist для AI-кравлерів
(GPTBot, OAI-SearchBot, ClaudeBot, anthropic-ai, PerplexityBot, MistralAI-User, Google-Extended)
і блокує AhrefsBot — переносимо як є.

## Структура сторінок (узгоджено)

```
/                                  Головна — хаб
/products/                         Прилади BMS — каталог + порівняльна таблиця
/products/bms-m/                   24 000 ₴ · обличчя, шия
/products/bms-pro/                 32 000 ₴ · шия, спина
/products/bms-nexus/               48 000 ₴ · два канали
/products/bms-quadro/              83 000 ₴ · роликовий вузол, спина
/how-it-works/                     Метод + сфери застосування + кому корисно
/documents/                        Документи — індекс
/documents/passport/               Паспорт
/documents/declaration/            Декларація відповідності UA.TR.D.00159-25
/documents/technical-conditions/   Технічні умови (ТУ)
/about/                            ТОВ «УКРСИСТЕМС», Олександр Бабак
/contacts/                         Контакти
/faq/                              Питання та відповіді (FAQPage schema)
/privacy-policy/                   Політика конфіденційності
```

Рішення, зафіксовані під час обговорення:

- «Сфери застосування» і «Кому корисно» — всередині `/how-it-works/`, окремої сторінки немає.
- Документи — під `/documents/`, кожен документ має власну сторінку.
- Ціни публічні, з позначкою «орієнтовна ціна».
- Головна дія — телефонний дзвінок. Онлайн-кошика немає.
- Вміст документів має бути **текстом у HTML**, не лише PDF-кнопкою: PDF погано індексується Google і майже не читається AI-кравлерами.

## Макети

| | Напрямок | Головний елемент | Шрифти |
|---|---|---|---|
| **A** | «Частота» — темна панель приладу | Робочий регулятор 20–40 Гц із семисегментним індикатором | Oswald + Onest |
| **Б** | «Практика» — тепла, преміальна | Схема зон впливу на силуеті | Spectral + Onest |
| **В** | «Каталог» — світлий, щільний | Таблиця порівняння 4 моделей | Manrope + Golos Text |

Усі три мають однаковий контент, липку кнопку телефону та нижню панель дзвінка на мобільному.
Сторінки макетів закриті `<meta name="robots" content="noindex,nofollow">`.

**Потрібно від замовника:**

- Окремі описи для кожної моделі. Зараз на сайті в усіх чотирьох однаковий текст,

  текстом конкурують між собою в пошуку.
- Паспорт і ТУ для BMS pro, Nexus, Quadro (наявні PDF лише для BMS m).
- Фотографії на однотонному тлі.
- Фото Олександра Бабака у нормальній роздільності (наявне — 147×147 px).
- Логотип у векторі (SVG); наявний — растр 512×512.
